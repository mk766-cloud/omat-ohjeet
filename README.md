## Git Tehtävä:

### 1.
Versiohallinta on tapa pitää kirjaa tiedostoihin tehdyistä muutoksista.
### 2.
Git on Linus Torvaldsin luoma ilmainen ja hajautettu versiohallintajärjestelmä. Linus loi Git-versionhallintajärjestelmän, koska hän ei ollut tyytyväinen muihin versionhallintajärjestelmiin.
### 3.
avaa pääte ja siirry haluamaasi kansioon komennolla ”cd hakemiston_polku”. Alusta komennolla ”git init” ja lisää tiedostot versiohallintaan komennolla ”git add” ja tallenna komennolla ”git commit -m”.
### 4.
Gitin tärkeimmät komennot ovat git init, git clone, git status, git add, git commit, git push, git pull ja git branch.
### 5.
Tee tarvittavat muokkaukset projektiisi, valitse halutut muutokset komennolla ” git add <tiedosto>”, liitä selkeä kuvaus muutoksista, tallenna muutokset paikalliseen historiaan suorittamalla komento ”git commit -m "Commit-viesti"”.
### 6.
-Komento ” git reset --soft HEAD~1” poistaa commitin, mutta jättää muutokset valmiiksi.

-Komento ” git reset --mixed HEAD~1” poistaa commitin ja palauttaa muutokset unstaged-tilaan.
  	
-Komento ” git reset --hard HEAD~1” poistaa commitin ja kaikki tehdyt muutokset.
